# โฟลเดอร์คลิปวิดีโอ (`data/clips/`)

วางคลิป CCTV สั้น ๆ (`.mp4`, `.mov`, `.avi`, `.mkv`) ไว้ที่นี่ แล้วรัน `make detect` หรือกดปุ่มประมวลผลคลิปในหน้า `/settings`

## การตั้งชื่อไฟล์

```
cam{ID}_{zone}_{YYYY-MM-DD}_{HHMM}.mp4
```

| ตัวอย่างชื่อไฟล์ | กล้อง | โซน | วันเวลา |
|---|---|---|---|
| `cam1_entrance_2026-09-29_0815.mp4` | cam1 | entrance (ทางเข้า) | 29 ก.ย. 2026 08:15 |
| `cam2_crane_2026-09-29_1405.mp4` | cam2 | crane (พื้นที่เครน) | 29 ก.ย. 2026 14:05 |
| `cam3_scaffold_2026-09-30_1030.mov` | cam3 | scaffold (นั่งร้าน) | 30 ก.ย. 2026 10:30 |

- `zone` ใช้ได้เฉพาะ a-z และ 0-9 (ไม่มีขีดหรือช่องว่าง) โซนที่รู้จัก: `entrance`, `crane`, `scaffold`, `floor3`, `warehouse` (ตั้งโซนใหม่ได้ ระบบจะแสดงชื่อตามที่ตั้ง)
- ถ้าชื่อไฟล์ไม่ตรงรูปแบบ: กล้องและโซนจะเป็น `unknown` และใช้เวลาแก้ไขไฟล์ (mtime) แทน

## สัญญาอนุญาต (License)

ให้ใช้เฉพาะคลิปที่มีสิทธิ์ใช้งาน (เช่น Pexels / Pixabay) หรือคลิปที่ถ่ายเองโดยได้รับอนุญาต
และ **บันทึกแหล่งที่มาและสัญญาอนุญาตของทุกคลิป** ในตารางใน `README.md` หลักของโปรเจกต์

ไฟล์ README นี้ไม่ถูกประมวลผลเพราะระบบอ่านเฉพาะไฟล์วิดีโอ
