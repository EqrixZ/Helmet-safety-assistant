# โฟลเดอร์เอกสารกฎระเบียบ (`data/regulations/`)

โฟลเดอร์นี้เก็บ **เอกสารกฎหมาย มาตรฐาน และระเบียบความปลอดภัย** ที่ผู้ช่วย AI (หน้า `/assistant`) และระบบสร้างรายงาน (หน้า `/reports`) ใช้อ้างอิงเวลาตอบคำถาม

> [!IMPORTANT]
> ไฟล์ `safety_rules_example.md` ในโฟลเดอร์นี้เป็นเพียง **ตัวอย่างกฎภายในไซต์งานที่เขียนขึ้นเพื่อการสาธิต** ไม่ใช่ข้อความทางกฎหมาย
> ก่อนใช้งานจริง ให้นำเอกสารฉบับจริงมาวางแทน แล้วลบหรือเปลี่ยนชื่อไฟล์ตัวอย่างออก

## ควรใส่เอกสารอะไร

ให้นำ **ข้อความฉบับจริงจากแหล่งที่เป็นทางการ** มาวางไว้ที่นี่ ตัวอย่างเช่น

- **กฎกระทรวงที่กำหนดมาตรฐานในการบริหาร จัดการ และดำเนินการด้านความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงานเกี่ยวกับงานก่อสร้าง** (ตามพระราชบัญญัติความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน) ดาวน์โหลดจากราชกิจจานุเบกษาหรือเว็บไซต์ของกรมสวัสดิการและคุ้มครองแรงงาน
- **มาตรฐานผลิตภัณฑ์อุตสาหกรรม (มอก.) สำหรับหมวกนิรภัยสำหรับงานอุตสาหกรรม** จากสำนักงานมาตรฐานผลิตภัณฑ์อุตสาหกรรม (สมอ.)
- **ระเบียบหรือคู่มือความปลอดภัยภายในบริษัท/โครงการ** เช่น ข้อกำหนดการสวมอุปกรณ์ PPE ในแต่ละโซน และบทลงโทษภายใน

> ระบบนี้ไม่ได้แนบข้อความกฎหมายฉบับจริงมาให้ ผู้ใช้ต้องจัดหาเอกสารที่ถูกต้องและเป็นฉบับล่าสุดเอง
> และควรตรวจสอบกับผู้เชี่ยวชาญด้านความปลอดภัย (จป.) หรือฝ่ายกฎหมายก่อนนำคำตอบของ AI ไปใช้

## รูปแบบไฟล์ที่รองรับ

| นามสกุล | หมายเหตุ |
|---|---|
| `.md` | แนะนำ: อ่านง่าย ใช้หัวข้อแบ่งหมวดได้ |
| `.txt` | ข้อความล้วน (UTF-8) |
| `.pdf` | ระบบดึงข้อความด้วย `pypdf`; PDF ที่เป็นภาพสแกนจะดึงข้อความไม่ได้ ต้องทำ OCR หรือแปลงเป็น `.txt` ก่อน |

อัปโหลดได้ 2 วิธี: วางไฟล์ลงโฟลเดอร์นี้โดยตรง หรืออัปโหลดผ่านหน้า **ตั้งค่า (`/settings`)** ในแดชบอร์ด

## ระบบใช้ไฟล์เหล่านี้อย่างไร

- **ทุกไฟล์ในโฟลเดอร์นี้ยกเว้น `README.md`** จะถูกอ่านและใส่เข้าไปใน context ของ LLM ทั้งฉบับ (context stuffing ไม่มีการตัดแบ่งหรือค้นหาแบบ vector)
- แต่ละเอกสารจะขึ้นต้นด้วยหัวข้อ `### เอกสาร: {ชื่อไฟล์}` เพื่อให้ AI **อ้างอิงชื่อไฟล์** ในคำตอบได้ จึงควรตั้งชื่อไฟล์ให้สื่อความหมาย เช่น
  - `กฎกระทรวง_ความปลอดภัยงานก่อสร้าง.pdf`
  - `มอก_หมวกนิรภัย.md`
  - `ระเบียบภายใน_โครงการA.md`
- ไฟล์ `README.md` นี้ **ไม่ถูกส่ง** ให้ LLM และไม่แสดงในรายการเอกสาร

## ข้อควรระวังเรื่องขนาด

เอกสารทั้งหมดถูกส่งไปพร้อมกับทุกคำถาม จึงกินพื้นที่ context window ของโมเดลโดยตรง

- พยายามให้ขนาดรวม **ไม่เกินประมาณ 50,000–100,000 ตัวอักษร** (ขึ้นกับโมเดล โมเดลเล็กบน Ollama อาจรับได้น้อยกว่านี้มาก)
- ตัดเฉพาะหมวด/ข้อที่เกี่ยวกับหมวกนิรภัยและงานก่อสร้าง แทนการใส่เอกสารทั้งเล่ม
- เอกสารยิ่งยาว ค่าใช้จ่ายต่อคำถามยิ่งสูง และคำตอบอาจช้าลง
- ตรวจดูจำนวนตัวอักษรของแต่ละไฟล์ได้ที่หน้า `/settings` (ค่า `chars` จาก `GET /api/regulations`)
